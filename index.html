Hybrid Retrieval
Dense vector search (sentence-transformers + ChromaDB/FAISS) fused with sparse BM25 keyword matching via Reciprocal Rank Fusion. A cross-encoder reranker scores the merged results before passing to the LLM.
ChromaDBFAISSBM25Cross-EncoderRRF
📋
Structured Data Layer
Course codes, prerequisites, credits, faculty, and schedules parsed into SQLite for deterministic lookups - so "What are CP317's prerequisites?" is never left to vector search guessing.
SQLiteDeterministicStructured retrieval
🛡️
Zero-Hallucination Design
Domain guard, referentless query detection, entity-history resolution, and a strict grounding prompt that enforces source citation (URL + retrieval date) on every single answer.
Domain guardCitation enforcement0% hallucination
🔄
Self-Healing Pipeline
Weekly scheduled re-crawl keeps content fresh. 235-test automated regression suite runs after every change. Version-aware course retrieval prevents stale data from surfacing.
