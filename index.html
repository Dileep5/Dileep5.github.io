Hybrid Retrieval

Combines BM25 keyword retrieval and dense vector search using ChromaDB. Reciprocal Rank Fusion merges the candidate rankings, followed by cross-encoder reranking.

🗃️

Structured Data Layer

SQLite supports structured lookups for course, program, and faculty information, reducing dependence on generated answers for exact factual queries.

🛡️

Grounding & Refusal

Domain checks, source-aware prompting, and refusal handling help the assistant avoid answering unsupported or unrelated questions. These safeguards reduce risk, but do not guarantee perfect accuracy.

🔄

Refresh & Regression Testing

GitHub Actions schedules content refreshes. Automated Streamlit AppTest regression checks help identify failures after application and data updates.
